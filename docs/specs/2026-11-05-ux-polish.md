# 2026-11 UI/UX 打磨（桌面端 + 共享包）

> Status: Approved
> Owner: desktop app 维护者
> Last updated: 2026-11-05

**Objective:** 落地 2026-11-05 UI/UX 审查中桌面端对话界面（C1–C8）与外壳/管理页（S1–S6）的 14 条发现。每条的问题、代码证据与「现状 / 建议」mockup 见审查页 `/Users/codfrm/Code/agentre/ux-review/desktop-chat.html#fN` 与 `desktop-shell.html#fN`（仓库外，未提交；本轮 `.dev-kit/artifacts/2026-11-05-ux-polish/` 下有副本）。本文件只记录**已定的需求与决策**；mockup 与本文冲突时以本文为准。

**Hard invariants:**
- 不加解释性状态 banner：状态用按钮态/指示器等 affordance 表达。
- 界面不贴机器原话：英文/Go 错误串一律转成中文事实句，原文只进默认折叠的「详情」或 `title`，并按类别决定给不给出口。
- 不新增 design token；只用 `packages/agentre-ui/styles/tokens.css` 已有的。
- 共享包 `@agentre-hub/agentre-ui` 的新 prop 一律可选，agentre-server 不传时行为与今天完全一致（本轮不改 agentre-server 的钉）。
- 不改 `pkg/wire`、`pkg/syncwire`；不加迁移。
- 每条行为改动先写失败测试（TDD）；i18n 的 zh-CN 与 en 同步。

## Requirements

### 对话界面

**C1 Tab 位置只由用户改变**（高）
- 会话状态变化（running / waiting / error / turn end / 审批 / 提问）不再移动 tab。删除 `chat-streams-host.tsx` 的 7 处 `bumpSessionTabToAfterPinned` 调用及因此失去调用方的 bump 代码（`chat-tabs-store` 的 bumpToAfterPinned、`use-attention-bump.ts`，以 grep 核实无其他生产引用为准）。
- 需要关注的会话在 tab 原位用现有审批/出错药丸与状态点表达；当该 tab 落在溢出菜单内不可见时，溢出按钮上挂 `status-waiting` 色计数。
- running 态 tab 只显示 spinner，不再同时画 StatusDot。
- 验收：运行中切换会话状态后 ⌘1–9 映射不变；测试覆盖「当前 tab 不被移动」与溢出计数。

**C2 停止进入输入框提交位，Esc 中断**（高）
- 共享 `ChatComposer` 新增可选 `running` / `onStop` / `stopping`。running 且草稿为空：提交位是停止键；running 且有草稿：停止键与发送键并排，发送键 tooltip 为「AI 完成后插入 (Enter)」（沿用现有 insertAfterAI 排队语义）。
- 焦点在输入框、草稿为空、无 slash/mention 弹层（`event.defaultPrevented` 为假）且不在编辑态时，Esc 触发停止。
- 点下停止后停止键变 spinner 并禁用，直到回合结束（宿主 `use-chat-actions` 增加 stopping 状态）。
- 决策：顶带的停止键保留，作为第二入口，共用同一 stopping 态。
- 验收：共享包测试覆盖三种提交位形态与 Esc 的触发/不触发条件；未传 prop 时快照与今天一致。

**C3 回合失败卡分类成中文事实 + 分类出口**（高）
- 共享包新增 `classifyTurnFailure(errorText)` → `overloaded | rateLimited | authExpired | processExited | network | unknown`，用真实 errorText 样本做表驱动测试。
- ErrorCard：标题一句中文事实；原文放进默认折叠、等宽、可复制的「详情」。出口：overloaded/rateLimited/network → 「重试这一轮」（重试同一条用户消息，不弹永久丢失确认）；authExpired → 命令卡（如 `claude /login`，按后端类型给命令），不给重试；processExited/unknown → 「继续」与「重新生成」。
- 「继续」发送 i18n 文案（zh「继续」），不再发英文 `continue`；页脚已有「重新生成」时卡片内不重复。
- 决策：分类在共享包前端完成，不改后端/wire（errorText 的源头就是 CLI 输出串，加 kind 需要成对改 wire，不在本轮）。分类函数是唯一的匹配点，C8 和 notice/turn-notify 复用它。

**C4 工具审批卡**（中）
- 待审批时默认展开；正文按工具给可读摘要：Edit=路径+小 diff，Write=路径+行数，Bash=命令，其他退回格式化 JSON。
- 按钮主次：「允许」primary；「本会话始终允许」ghost；「拒绝」ghost + destructive 文字色。`tool-approval/card.tsx` 的批准/拒绝同样调整。
- 卡片出现且用户不在输入框打字时，焦点落到「允许」；Enter 允许、Esc 拒绝，按钮上显示 kbd。
- 回到底部药丸：视口下方有未决项时显示「N 项待处理」（宿主传入独立的 pendingBelow，不再挂在 catchUp 上）。

**C5 重试提示改为指示器行**（中）
- 删除对不存在的 `status-warning` 类的引用。`RetryNoticeCard` 改为与断连/压缩指示器同位、互斥的一行：`status-waiting` spinner + 中文事实 + 次数（如「上游连接中断，正在重试 2/10」），原文进 `title`。
- 加守卫测试：源码中出现 tokens.css 未定义的 `status-*` 颜色类时失败。

**C6 任务进度条压成一行**（中）
- 折叠态一行：`3/7` + 当前任务（截断）+ 细进度条 + 展开箭头；去掉「任务进度 / 已完成 / 百分比」重复表达。运行中 spinner 用 `status-running`。展开态列表不变。
- 同步修正 `docs/design.md` §9 In-progress 行中「spinner tinted text-status-waiting」的描述。

**C7 去掉常驻快捷键提示**（低，按用户决定缩小范围）
- `ChatComposer` 不再默认渲染「↵ 发送 · ⇧↵ 换行」；`shortcutsHint` 仍可由宿主显式传入；编辑态的「↵ 保存 · Esc 取消」保留。
- 决策：推理强度的位置（决策 9：紧邻提交键）与三个设置药丸的样式**本轮都不动**。

**C8 通知卡时间与自动清除**（低）
- `notification-toast-store` push 时记录 `createdAt`，显示相对时间（复用宿主已有格式化函数）。
- 会话的 attention 被清除时（审批已处理、会话被打开、新一轮开始）自动移除该会话的 waiting/error 通知；同一会话只保留最新一张。
- 出错通知正文用 C3 的分类句；去掉越出规范的 `z-[100]`，层级改由 design.md 的层级规范/portal 顺序决定。

### 外壳与管理页

**S1 看板删除可撤销**（高）
- 宿主 `use-board.ts` 维护待删集合：点删除后卡片立即隐藏，Sonner toast「已删除「标题」」带「撤销」；约 6 秒后才调用 `IssueDelete`（同步随之推迟）；撤销恢复原位；组件卸载/窗口关闭前立即提交未决删除。共享包 card-menu / task-form 端口签名不变。

**S2 「Agent 缺配置」统一路径**（高）
- 深链函数从 `not-chattable-dialog.tsx` 抽到宿主 `lib/`，三处共用。
- LLM 供应商页的黄色 Alert 换成页内「待补齐」清单：每行 Agent 头像 + 名称 + 缺哪一环 +「去配置」（深链 `/org` 并带 `orgSelection`）。数据源 `useChatAgents().agents[].blockReason`，不新增 RPC。
- 对话空态「去组织架构配置」：只有一个缺口 Agent 时直接深链到它；多个时进组织架构并预选新增的「待配置」筛选。
- 组织架构索引行给不能对话的 Agent 加 6px `status-waiting` 点（共享包 `org/org-agent-row.tsx` 可选 prop），可读名带原因。
- 设置导航的点把缺口信息并入按钮可读名（如「Agent 后端，有 2 个 Agent 未配置」）。

**S3 状态栏与待处理入口**（中）
- 摘要按会话计数（「5 个会话运行中」），Agent 数进 tooltip。
- 待处理按钮：多于 1 条时是向上的 Popover，按「待审批 → 未读」分组列出会话，点哪行开哪行；只有 1 条时直接跳转且不画 chevron。
- 只有待审批才把状态点染成琥珀；只有未读时状态点保持 running/idle，「N 条未读」用 muted-foreground。
- 不在 /chat 且有待审批时，图标栏「对话」按钮显示琥珀 badge，可读名追加「，N 个待审批」（`SidebarButton` badge 加 tone 参数）。

**S4 项目合并结果预览**（中）
- 后端新增只读 `ProjectMergePreview(sourceID, targetID)`，复用 `chooseMergeWinner`，返回 keep / drop 两侧摘要（名称、父路径、是否账号侧）。规则只保留后端一份。
- 选好目标后显示「合并后保留 / 并入后消失」，确认按钮写「合并为 X」。
- 候选列表改为「父项目 / 子项目」路径式显示，支持输入过滤；说明列表项目符号用中性色，不借状态色。

**S5 管理页错误分类与出口**（中）
- 宿主 `lib/` 新增错误分类（在 `lib/error-detail.ts` 基础上，优先按后端已有的 `code.*` 错误码，若 Wails 层未透传码则补透传）：`offline | conflict | notFound | invalidFile | permission | unknown`。
- 逐页替换 `String(e)` / `e.message` 直出：项目排序（toast「项目顺序没保存，已恢复原来的顺序」+ 重试，删顶部红条）、合并、删除（接上共享 `ProjectDeleteDialog` 已支持的 failure.kind）、看板写入、数据导入导出（解析失败「这个文件不是 Agentre 导出的备份」+ 重新选择文件）、同步、设备升级。unknown：中文标题 + 折叠详情。
- 不做全局文本改写。

**S6 快捷键可发现性**（低）
- 图标栏 tooltip 显示页面快捷键（从 bindings 读，`SidebarButton` 加可选 `shortcut`）。
- 对话空态文案去掉写死的「⌘P」与中英混排，chord 用 `formatChord` 按平台生成。
- 引导态（`!hasChattable`）不渲染 tab 快捷键 `ChatShortcuts`。
