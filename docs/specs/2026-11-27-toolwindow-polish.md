# 对话页工具窗外观与布局入口打磨

> Status: Approved
> Owner: 桌面端
> Last updated: 2026-11-27

**Objective:** 对话页工具窗的焦点框在浅色、深色下四边都看得见。工具窗与对话卡片用同一套外观。标题栏右上角给出会话列表、底部工具窗、右侧工具窗三个看得见的开关。恢复的标签不再显示成「(会话)」。

**Hard invariant:** 不改变 `docs/specs/2026-11-24-chat-right-toolwindows.md` 已约定的槽位、视图模式、快捷键（⌃1–6、⌃\`、⌘0、⇧⌘\\、⇧⌘'）、窄窗口与专注规则。现有快捷键的含义不变，只新增。

## Problem

1. **焦点框被内容盖住。** 用户反馈：「终端工具窗（底部）、网页预览的边框还被遮挡了」。
   - 已验证的原因：工具窗没有边框，只有获得焦点时的 2px 内描边（`focus-within:focus-outline-inset`，`tool-window-frame.tsx:217`）。它画在窗口内侧，终端底色与网页 iframe 盖在它上面，于是底边、侧边断开。
   - 隔离验证台浅色、深色截图的 4× 放大里，终端窗口的下边缘都不见了。证据：`.dev-kit/artifacts/2026-11-27-toolwindow-polish/mockups/img/ux-corners-*.png` 上排。
2. **工具窗与对话卡片外观不一致，显得粗糙。** 用户反馈：「ui/ux 有点丑」。已验证：
   - 工具窗圆角 10px，对话卡片 12px。
   - 停靠的工具窗没有阴影，对话卡片在浅色下有 `--sheet-shadow`。
   - 终端主题把底色硬写成页面底色（`terminal-theme.ts:10`，浅 `#fafafa`、深 `#18191b`），而窗口是 `--sheet`（`#fff` / `#1b1c1f`），所以终端正文和它的标题栏是两种灰。
3. **看不出会话列表怎么收起、怎么拿回来。** 用户反馈：「左侧对话是怎么隐藏的，看不太出来」。
   - 已验证：目前只有 ⌘0，或在对话页再点一次左侧「对话」图标，两者都没有任何可见入口。
   - 收起后屏幕上什么都不留（`session-list-sidebar.tsx:13-17` 只给侧栏加 `hidden`）。
4. **恢复的标签显示成「(会话)」和「?」。**
   - 已观察：验证台重启后，标签栏里会话 6 的标签标题是「(会话)」、头像是「?」。点开后能正常加载，标题和头像也随之纠正。
   - 已验证的直接原因：标签标题只读会话元数据缓存（`use-tabs-view.ts:129`），缓存里没有这个会话就回落到「(会话)」。会话 6 不在会话列表已加载的那一页里，标签又没被激活，于是一直没有人去取它的元数据。
   - 缓存还有哪些填充路径没覆盖到，待实现时复现确认。

## Actors and user stories

1. 作为在对话页同时开着终端和网页预览的用户，我想一眼看出焦点在哪个工具窗，并且框不被内容盖住，这样我知道快捷键和输入会作用到哪里。
2. 作为在浅色或深色下工作的用户，我想工具窗和对话卡片看起来是同一套界面，而不是拼起来的。
3. 作为想腾出空间的用户，我想在固定、看得见的位置收起或展开会话列表、底部工具窗、右侧工具窗，并且知道对应的快捷键。
4. 作为重启应用后的用户，我想每个恢复的标签直接显示正确的会话标题和 Agent 头像。

## Design decisions

| # | Decision | Basis and rejected option |
|---|---|---|
| 1 | 焦点框保留 2px，画在工具窗内容之上，四边完整；鼠标点进去和键盘进入都显示 | 用户选 B2（「可以b2」）；用户要的是框不被遮挡，不是去掉框。Rejected：A（不画框，改用标题栏染色）——用户认为看不到框就等于被遮挡；B（1px）——缩小显示时下边缘看不出来 |
| 2 | 工具窗的圆角与停靠状态下的阴影与对话卡片一致；浮动、覆盖、最大化仍用现有的浮层阴影 | 用户确认方案时包含此项（A / B / B2 共有）。Rejected：保持 10px、无阴影——这正是「拼起来」感的来源 |
| 3 | 终端放在工具窗里时，底色等于所在窗口的底色（浅色、深色都是），ANSI 配色不变；别处的终端保持现状 | 终端正文与标题栏同色。终端组件也被其它宿主使用，所以只改工具窗里的这一处。Rejected：全局把终端主题底色改成 `--sheet`——会改到工具窗以外的终端 |
| 4 | 标题栏右端加一组三个布局开关，从左到右是：会话列表、底部工具窗、右侧工具窗。只在对话页出现；Windows 上排在窗口控制按钮左边 | 用户提出「像 vscode 一样，坐在右上角」，选三按钮（Recommended）。Rejected：四按钮加「布局」菜单——专注模式与恢复默认布局已在工具窗菜单和快捷键里，右上角保持简单；只放会话列表一个；标签栏最左按钮；列表头按钮 |
| 5 | 开关图标里填实的那一块表示该区域正显示着。悬停提示给出名称和快捷键，并随状态在「收起 / 展开」或「隐藏 / 显示」之间切换 | 与 VS Code 一致，一眼看出现状。Rejected：只用按下底色区分——在 chrome 底色上对比不足 |
| 6 | 新快捷键：底部工具窗 ⌘J，右侧工具窗 ⌥⌘B（Windows / Linux 为 Ctrl 对应组合）。两者进快捷键注册表，可在快捷键设置里看到、改绑 | 沿用 VS Code 的习惯；已验证注册表里没有用到 J、B 的组合。会话列表仍是 ⌘0 |
| 7 | 区域开关作用于整个区域：<br>• 隐藏时，记住该区域各槽位正显示的工具窗，再全部隐藏。<br>• 显示时，恢复记住的那些。<br>• 没有记录时，显示该区域里按图标条顺序排第一个的工具窗（出厂布局下右侧是「大纲」、底部是「终端」）。<br>• 区域里没有任何工具窗时，开关不可点 | 和逐个点图标条的结果一致，又能一键收放。Rejected：区域开关只记「开 / 关」，不记具体窗口——再次显示时会丢掉用户刚才看的那个 |
| 8 | 开关反映屏幕上的实际状态：<br>• 窄窗口规则把右侧工具窗收起时，右侧开关显示为未显示；点它按现有窄窗口规则把右侧工具窗以覆盖方式显示出来。<br>• 专注模式（⇧⌘\\）下，底部、右侧开关显示为未显示；点它们与在图标条上打开工具窗效果相同 | 不为开关另立规则，复用 2026-11-24 spec 的窄窗口与专注规则 |
| 9 | 恢复的会话标签不需要先被激活，也要显示该会话真实的标题与 Agent 头像 | 用户确认把这个问题并入本轮（「并进这一轮」） |

## 焦点框与工具窗外观

对话页任何一个工具窗里有焦点时，围绕这个工具窗显示一圈 2px 的焦点色描边，画在终端、网页预览、列表等内容之上。在浅色、深色下，停靠、浮动、覆盖、最大化各种呈现方式里，四条边和四个圆角都完整可见。焦点离开工具窗时描边消失。同一时刻最多一个工具窗带描边。

停靠的工具窗与对话卡片用同一圆角，并有同一卡片阴影。浮动、覆盖、最大化的工具窗保持现在的浮层阴影。标题栏不加底色，标题、计数、⋯ 与隐藏按钮保持现状。

终端工具窗的正文底色与所在窗口相同（浅色、深色），光标和 ANSI 16 色不变。项目里打开的独立终端标签，以及其它宿主里的终端，外观不变。

网页预览里嵌入的页面照旧铺满正文区。焦点描边画在页面之上，不被页面盖住。

## 标题栏布局开关

对话页的标题栏右端（命令面板触发器之后，Windows 窗口控制按钮之前）显示三个图标按钮，从左到右是：会话列表、底部工具窗、右侧工具窗。离开对话页，这组按钮不显示。按钮不参与标题栏拖动，双击它们不会最大化窗口。

- **会话列表。**
  - 列表展开时，图标左侧那块填实，悬停提示「收起会话列表 ⌘0」；收起时空心，提示「展开会话列表 ⌘0」。
  - 点击与按 ⌘0、或在对话页再点左侧「对话」图标效果相同。
  - 收起状态照旧持久化。
- **底部工具窗。**
  - 底部任一槽位有工具窗显示着时，图标下方那块填实，提示「隐藏底部工具窗 ⌘J」；否则空心，提示「显示底部工具窗 ⌘J」。
  - 点击或按 ⌘J 按决策 7 隐藏或显示。
  - 底部两个槽位都没有分配工具窗时，按钮置灰不可点，提示说明底部没有工具窗。
- **右侧工具窗。**
  - 与底部相同，对应右上、右下两个槽位，快捷键 ⌥⌘B，图标右侧那块填实。
  - 窄窗口下按决策 8。

开关记住的「隐藏前显示着哪些窗口」随布局一起持久化，重启后再按显示仍能恢复。「恢复默认布局」会清掉这份记录。

按钮有可读名称，并以按下状态反映区域是否显示。键盘可以 Tab 到它们，焦点可见。三个按钮的提示文字与名称都进 i18n（中、英）。

## 恢复的会话标签

应用启动或重新加载后，每个恢复出来的会话标签，不论是否激活、不论会话是否在会话列表已加载的那一页里，都显示该会话真实的标题与 Agent 头像。取元数据期间可以短暂显示占位。

取不到元数据（会话已不存在、或读取失败）时，标签保持现在的占位标题「(会话)」，不报错打扰。是否连带清理已不存在会话的标签，保持现有行为不变。

## Out of scope

- 「布局」菜单、VS Code 的 Customize Layout 式配置（用户选了三按钮）。
- 工具窗内部内容（列表、网页预览、终端输出）的样式改动，除终端底色外。
- 其它页面（组织、Hooks 等）的左栏收起入口。
- 其它宿主（agentre-server 网页端）里的布局开关；网页端没有这套工具窗。
- 远端设备离线时「同一份代码上在跑」查询记 error 级日志的问题，只记录不在本轮修。
