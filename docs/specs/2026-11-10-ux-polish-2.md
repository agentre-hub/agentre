# 2026-11 UI/UX 打磨（第二轮：对话周边界面 + 管理页表单与弹窗）

> Status: Approved
> Owner: desktop app 维护者
> Last updated: 2026-11-10（计划侦察后修订：B6 事实、B7 开启方式、A3 判据、兼容性清单）

**Objective:** 落地 2026-11-10 静态审查的 18 条发现（对话周边 A1–A10、外壳与管理页 B1–B8），让“操作之后发生了什么”在界面上如实可见：失败不静默、未保存不被覆盖、不可逆操作不一点即生效、失败说中文事实而不是机器原话。

每条的「现状 / 建议」对比 mockup 与代码证据在 `.dev-kit/artifacts/2026-11-10-ux-polish-2/mockups/`（本地、未提交）。mockup 与本文冲突时以本文为准。

**Hard invariants:**
- 不加解释性状态 banner；状态用控件自身（按钮态、指示点、字段错误）表达。
- 界面不贴机器原话：正文是本地化事实句，原文只进默认折叠的「详情」或 `title`。
- 不加可见的复制按钮；只读文本可选中。
- 不新增 design token；只用 `packages/agentre-ui/styles/tokens.css` 已有的。
- 共享包 `@agentre-hub/agentre-ui` 的新 prop 一律可选，agentre-server 不传时行为与今天一致。
- 不改 `pkg/wire`、`pkg/syncwire`；不加迁移。
- 每条行为改动先写失败测试；zh-CN 与 en 文案同步。

## Actors and user stories

1. 作为用户，我做了一个操作（切模型、建 Agent、改名、删除、保存脚本），想确切知道它成没成；没成时知道原因并能再试。
2. 作为用户，我不想因为误点而丢掉没保存的内容，或停掉一个跑了很久的进程。
3. 作为在另一台设备上看远端会话的用户，我想看清 AI 在问什么、要运行什么，再作答或授权。

## 对话周边界面

**A1 远端会话面板**
- 对端有未决提问时，面板显示与本机对话相同的提问卡：全部题目与选项可见，可作答提交，也可点「跳过」；提交的是用户选的答案。
- 对端有未决工具授权时，显示与本机对话相同的授权卡：工具输入的可读摘要、「允许」primary /「本会话始终允许」/「拒绝」。
- 对端一轮结束后，转录末尾不再显示生成中指示。
- 接入失败页有「重试」（重新接入），原始错误进折叠详情。提交答复 / 授权失败时提示条说本地化事实句，可关闭；「已被处理」用中性底。

**A2 输入框药丸切换失败**
- 模型、权限模式、思考强度任一切换失败：值回到原值，同时出现 toast「没切换成功，仍是 <原值>」，原文进详情。
- 模型弹层：切换失败后再打开，供应商列表仍在，失败句在列表下方一行、destructive 色。只有目录拉取失败才顶替列表，同样用 destructive 色。

**A3 提问卡**
- 提交失败且原因是提问已不存在：保持现状（锁卡、「已失效」）。判据是错误文本命中运行时的“无等待中的请求”信号（`internal/pkg/agentruntime/errors.go:30`），在共享包里集中一处、表驱动测试；认不出的一律按可重试处理。其他失败：卡不锁、选择保留、显示「没提交成功」+ 折叠详情，可再次提交。
- 多题时漏答：切到第一道缺答的题，错误显示在那一题下。

**A4 停止与结束**
- 停止子代理、停止后台任务：点下后按钮变 spinner 并禁用，直到状态变化或失败；命中区 24px。
- 结束进程：图标与「停止」不同；第一次点击按钮变红色「结束？」，约 2 秒内再点才执行，否则复原；执行中为 spinner；成功后 toast「已结束 <命令>」。
- 进程行不再有 hover 底；命令可换行、可选中；cwd 从头部截断。

**A5** 进程有多个端口时，每个端口是一个可点的按钮，打开对应端口；单端口时保留现有的打开键。

**A6** 导入对话框：扫描失败显示本地化事实句 +「重新扫描」+ 折叠详情；预览失败、导入失败用同一写法。

**A7** 工具授权卡与计划卡提交失败显示本地化事实句，原文进 `title`；不再出现英文 `Submit failed`。

**A8** 大纲的失败小标与读屏文本走 i18n；目录页指定路径失败、打开文件 / 在文件管理器中显示失败、终端启动失败：标题是本地化事实句，原文进 toast 描述或详情。

**A9** 终端在连接中时显示居中的 spinner 与「正在连接终端…」；断线后只保留红条（不再同时弹 toast），红条上有「新开终端」与「关闭」。

**A10** 侧栏「大纲 / 变更 / 目录」与「本次会话 / 未提交」支持方向键切换；根切换下拉标出当前根并显示父目录路径；执行位置列表与大纲当前项带正确的选中语义。视觉不变。

## 外壳与管理页

**B1 组织架构写失败**
- 新建、改名、改提示词、移动、排序、删除任一写入失败：页面内容保持，不再整页替换。
- 弹窗内发起的写入失败：弹窗留着、输入保留，错误显示在弹窗页脚；后端给了错误码时说具体事实（如「已经有同名 Agent」），否则通用句，原文进 `title`。
- 详情页自动保存失败：页脚显示「保存失败」与「重试」。
- 拖动 / 排序失败：toast 报错，列表恢复原序。
- 首次加载失败：整页「加载失败」+「重试」，不贴原文。

**B2 Hooks**
- 草稿与已保存内容不同时，该 Hook 在左栏行尾有一个小点。
- 有未保存修改时点另一条 Hook 或「＋」：先问「放弃对「<名称>」的修改？」，「继续编辑」留在原处，「放弃修改」才切换。没改过不问。
- 启用 / 停用只改该 Hook 的启用状态，不动草稿。
- 有未保存修改时运行键是「保存并运行」：先保存，成功后试运行；保存失败不运行。
- 保存、启停、删除、运行的结果用 toast；页面顶部不再有提示条。删除失败说「删除失败」。
- 列表加载失败是独立一态（「Hooks 没有加载出来」+「重试」），不显示空态的新建引导。

**B3 新建 Agent / 部门** 提交期间按钮为 spinner 并禁用，弹窗不可关闭，重复触发不产生第二条；成功后新建项在树中被选中，祖先展开并滚动到可见，右侧显示它的详情。

**B4 确认类弹窗** 会话改名、删除会话、移除设备、设备改名、TLS 信任应用：确认键进入进行态，成功才关窗；失败留在窗内，显示事实句 + 折叠详情。删除会话的确认文案带会话标题。

**B5 机器原话** 清单内各处改为本地化事实句 + 折叠详情（或 toast 描述）。新建项目 / 项目设置的写入失败按后端错误码映射到共享包已有的四类失败文案。

**B6 结果提示** 设置各页的成功结果统一为 toast；Agent 后端的行内测试失败贴在该行下方；共享提示条只用于失败，关闭键是 ×。

**B7 表单弹窗** Agent 后端编辑窗在保存或同步供应商期间不可关闭。Agent 后端编辑、新建 Agent、新建部门、新建项目：填过内容后点遮罩不关闭；Esc 与 × 照常关闭。共享包里的两个弹窗（Agent 后端编辑、新建项目）的草稿保护由宿主显式开启，agentre-server 不开启时行为不变。

**B8 配对表单** 地址与配对码在失焦或提交后才显示校验错误，之后随输入实时复验；本地代理页的端口字段同理。TLS 入口显示模式的本地化名称。

## Compatibility

- 共享包改动（提问卡失败分支、子代理卡停止态、模型弹层失败行、导入失败态、终端加载态与断线条、`DialogShell` 草稿保护、`FlashBanner`）对 agentre-server 均为可选 prop 或纯内部行为；A3 的“非失效失败不锁卡”、A7 的文案、B6 的 Agent 后端页“成功改 toast、提示条只承载失败且关闭键为 ×”、B7 的“Agent 后端编辑窗保存中不可关闭”是共享组件的默认行为变化，server 抬钉后跟随。
- 后端改动仅限 Wails 绑定层给组织架构与项目写入包 `codedError`，不改服务层语义。

## Out of scope

- agentre-server 抬钉接入本轮共享包改动（另起一轮）。
- 审查未读到的范围：会话索引行 / 工具栏 / 拖拽、命令面板、LLM 供应商表单、能力选择器、首次启动引导、思考块与 markdown 渲染。
- 实机视觉核对（对比度、暗色、动效）：验证台前端编译超过 300 秒启动上限，本轮未解决。
- 终端断线后重连同一会话；Hooks 以草稿试运行。
